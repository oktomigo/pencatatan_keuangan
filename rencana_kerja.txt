================================================================
RENCANA KERJA — APLIKASI PENCATATAN KEUANGAN HARIAN
Urutan: UI/Frontend dulu → Backend setelahnya
Stack : Vanilla JS + Tailwind CSS (UI) | Flask + MongoDB (API)
================================================================

PRINSIP KERJA:
- Fase 1–2 = UI & frontend sepenuhnya, data pakai mock object JS
- Fase 3+   = backend Flask + MongoDB, UI disambung ke API nyata
- Setiap step dikerjakan satu per satu, jangan loncat
- Selalu baca design.md sebelum mulai step UI apapun

ARSITEKTUR FRONTEND:
- HTML markup ada di templates/ (Jinja2, dirender Flask per route)
- static/js/ HANYA fungsi JS murni — behavior, event listener,
  animasi, validasi, update DOM — TIDAK generate HTML baru
- static/css/ berisi tokens.css dan main.css
- Flask serve satu template per route, bukan SPA

FASE 1 — FONDASI
(Buat semua file dasar sebelum mulai halaman)
================================================================

STEP 1.1 — Struktur Folder & File Kosong
  Buat semua folder dan file sesuai struktur di atas.
  Setiap template: skeleton Jinja2 yang extends base.html.
  Setiap JS: komentar satu baris + export function init() kosong.
  main.py: semua route (GET per halaman + API placeholder).

STEP 1.2 — Design Tokens CSS (static/css/tokens.css)
  Semua CSS custom properties dari design.md section 3:
  - Warna (--color-primary-*, success, warning, danger, info,
    surface, text hierarchy, border)
  - Tipografi (--text-display, heading, body, caption, number)
  - Spacing (--space-1 sampai --space-20, base 4px)
  - Border radius (--rounded-sm sampai --rounded-full)
  - Shadow (--shadow-sm sampai --shadow-nav)
  - Transition (--transition-fast sampai --transition-spring)

STEP 1.3 — Global Styles & Font (static/css/main.css)
  - Import tokens.css
  - Load font Plus Jakarta Sans dari Google Fonts
  - Base reset minimal
  - Utility: .text-income, .text-expense, .tabular-nums,
    .skeleton (animasi shimmer), .visually-hidden
  - Layout shell: #bottom-nav (visible <1024px), #sidebar-nav
    (visible >=1024px), #fab-add, #page-content

STEP 1.4 — base.html (Layout Shell)
  Jinja2 template dengan:
  - <head>: Tailwind CDN, Lucide CDN, tokens.css, main.css
  - Offline banner (id="offline-banner", hidden)
  - Toast container (id="toast-container", kosong)
  - <main id="page-content">: {% block content %}{% endblock %}
  - Bottom nav: 5 <a> dengan href Flask + data-nav-path
  - Sidebar: sama dengan bottom nav
  - FAB: <button id="fab-add">
  - Scripts: Lucide init + router.js + {% block scripts %}

STEP 1.5 — main.py (Flask Routes)
  Route halaman (GET → render_template):
    /onboarding, /dashboard, /transactions, /categories,
    /budgets, /reports, /recurring-bills, /savings,
    /export, /settings
  Route API placeholder (return jsonify):
    GET/POST /api/transactions
    PUT/DELETE /api/transactions/<id>
    GET/POST /api/categories
    GET/POST /api/budgets
    GET /api/dashboard

STEP 1.6 — utils.js
  Export: formatRupiah, formatDate, getMonthYear, daysFromNow,
  calcPercentage, getBudgetStatus, generateDeviceId, today

STEP 1.7 — mock.js
  Export MOCK object: categories (11), transactions (15),
  budgets (4), recurringBills (3), savingsGoals (3), dashboard
  Data konsisten (category_id nyambung antar entitas)

STEP 1.8 — toast.js
  Export showToast(message, variant, duration)
  Inject <div> toast ke #toast-container yang sudah ada
  Animasi via CSS class, auto-dismiss, stack max 3

STEP 1.9 — modal.js
  Export openModal, openBottomSheet, openConfirmDialog,
  closeModal, closeBottomSheet
  Inject overlay + panel ke body — bukan generate halaman baru
  Focus trap, focus restore, keyboard (Escape)

STEP 1.10 — router.js
  Navigasi pakai window.location.href = path (Flask serve template)
  Export: navigate(path), highlightNav()
  Pasang offline/online event listener
  FAB onclick handler

STEP 1.11 — state.js
  Export AppState: get, set, subscribe, getDeviceId, getCurrentPeriod
  Init deviceId dari localStorage (buat jika belum ada)
