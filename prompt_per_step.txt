CARA PAKAI:

ARSITEKTUR FRONTEND:
• HTML markup ada di templates/ (Jinja2, dirender Flask)
• static/js/ HANYA berisi fungsi JS murni:
    - Manipulasi DOM pada elemen yang sudah ada di HTML
    - Event listener (klik, input, submit)
    - Animasi dan transisi
    - Validasi form
    - Update data di DOM (innerHTML, textContent, classList)
  TIDAK boleh generate struktur HTML dari JS
• static/css/ berisi tokens.css dan main.css
• Data dummy ada di static/js/mock.js sebagai JS object

ATURAN YANG BERLAKU DI SEMUA PROMPT:
• Gunakan CSS custom properties dari tokens.css — JANGAN hardcode hex/pixel
  Contoh benar : color: var(--color-primary-500)
  Contoh salah : color: #0D9488
• Semua angka Rupiah pakai fungsi formatRupiah() dari utils.js
• Semua elemen interaktif minimum height 44px (var(--space-11))
• Fase 1–2: data dari mock.js, bukan fetch ke backend
• Fase 3–4: ganti mock dengan fetch ke Flask API

STEP 1.6 — Utility Functions (utils.js)
──────────────────────────────────────────────────────────────
Buat static/js/utils.js.
Semua fungsi di-export agar bisa diimport modul lain.

1. formatRupiah(number)
   Input: 1234567 → Output: "Rp 1.234.567"
   - Gunakan toLocaleString('id-ID')
   - Jika negatif: "−Rp 1.234.567" (bukan -Rp)
   - Jika 0: "Rp 0"

2. formatDate(dateStr, format)
   format 'long'  → "15 Oktober 2026"
   format 'short' → "15 Okt"
   format 'input' → "2026-10-15"
   format 'group' → "Hari Ini" / "Kemarin" / "15 Oktober 2026"

3. getMonthYear(date) → "Oktober 2026"

4. daysFromNow(dateStr) → integer
   Positif = ke depan, 0 = hari ini, negatif = sudah lewat

5. calcPercentage(value, total) → number (bisa > 100)
   Kembalikan 0 jika total = 0

6. getBudgetStatus(percentage)
   < 80   → 'safe'
   80–99  → 'warning'
   >= 100 → 'danger'

7. generateDeviceId() → string UUID v4 via crypto.randomUUID()

8. today() → string "YYYY-MM-DD" (untuk default value input date)

STEP 1.11 — Global State (state.js)
──────────────────────────────────────────────────────────────

STEP 2.12 — Responsive & Accessibility Pass
──────────────────────────────────────────────────────────────
Review templates dan CSS untuk memastikan responsive dan
accessibility bekerja di semua breakpoint.

Cek di templates (HTML attributes):
□ Semua tombol interaktif style="min-height:44px" atau class
□ nav[aria-label="Navigasi utama"] di base.html
□ Setiap progress bar: role="progressbar" aria-valuenow
  aria-valuemin="0" aria-valuemax="100" aria-label yang deskriptif
□ SaldoCard: aria-live="polite" pada elemen nominal
□ Error span: role="alert" aria-live="assertive"
□ Modal/sheet: role="dialog" aria-modal="true" aria-labelledby (di modal.js)
□ Focus kembali ke trigger element saat modal ditutup (di modal.js)

Cek di CSS (main.css):
□ Media query <768px: bottom nav visible, sidebar hidden
□ Media query >=1024px: sidebar visible, bottom nav hidden
□ #page-content margin-left 240px di desktop
□ FAB posisi benar di semua breakpoint
